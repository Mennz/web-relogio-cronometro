# Relógio e Cronômetro

Página com um relógio digital que atualiza sozinho a cada segundo e um
cronômetro com botões de iniciar, pausar e zerar. HTML, CSS e JavaScript
puro, sem nenhuma biblioteca.

## O que pratiquei

- `setInterval` e `clearInterval`
- Pegar hora, minuto e segundo com `Date`
- Formatar número com dois dígitos (`padStart`)
- Guardar o tempo decorrido numa variável e ir somando
- Desabilitar botão pra evitar clique duplicado criando intervalo repetido

## Como rodar

Só abrir o `index.html` no navegador.
